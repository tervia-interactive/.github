## What we're about

Tervia Interactive is an independent software development organization exploring how software can work, feel, and fit together.

Our projects range from low-level operating-system development to desktop platforms, utilities, and interactive experiments. We enjoy understanding the whole stack — not only making something run, but thinking through how it should behave, how people should use it, and what makes it worth using.

We value software that can be understood, changed, and improved. Not every project has to follow an established formula, and not every experiment has to become a product.

## Projects

### [tach](https://github.com/tervia-interactive/tach)

**An operating system with its own direction.**

tach is a ground-up operating-system project with a long-term goal of broad hardware and architecture compatibility. Its shell and command-line tools use familiar UNIX-like conventions, but the ambition goes beyond building another UNIX-like system.

We want tach to have an identity of its own: a practical filesystem that makes sense to newcomers, a window-based experience, and an ecosystem designed to feel like one coherent system.

Its influences come from different places:

| Inspiration | What we take from it |
| --- | --- |
| **Windows** | Familiar interaction, practical folder organization, and approachable window management. |
| **macOS** | Visual coherence, attention to detail, and the feeling of using a connected ecosystem. |
| **FreeBSD** | Freedom, simplicity, a lightweight approach, and respect for the system underneath. |

These are reference points, not blueprints. The goal is not to recreate any of them. It's to take the ideas that work and build something that feels distinctly like tach.

<sub>Current architecture work: i686 and x86_64 boot targets are working; ARM32, AArch64, RISC-V 32-bit, and RISC-V 64-bit support are under development.</sub>

[View tach →](https://github.com/tervia-interactive/tach)

### [Fanne Linux](https://github.com/tervia-interactive/fanne-linux)

**A desktop distribution built on Debian Unstable.**

Fanne Linux is a rolling Linux distribution focused on the desktop. It aims to provide a polished, dependable environment while keeping the system understandable, rebuildable, and open to modification.

The project is currently in its bootstrap stage. Its development image is a work in progress and is not yet intended for daily use.

[View Fanne Linux →](https://github.com/tervia-interactive/fanne-linux)

## How we approach software

- **Build with intent.** Features should have a reason to exist, and implementation details matter.
- **Keep things approachable.** A capable system does not need to make everyday tasks difficult.
- **Think beyond one machine.** Portability and compatibility are design goals, not afterthoughts.
- **Respect the user.** Prefer freedom, transparency, and room to experiment over unnecessary restrictions.
- **Care about the experience.** Good engineering and a good interface should complement each other.

## Development

Projects here do not all move at the same pace. Some are active development efforts, some are experiments, and some may be archived as ideas evolve.

For the most accurate information about a project's current state, build instructions, roadmap, and license, check its own repository. We try to keep those details close to the code rather than making promises on an organization page.

## Get involved

Found something interesting, have a question, or want to contribute?

Start with the repository related to your topic. Issues are a good place for bug reports and technical discussion; pull requests are welcome when they include context and a clear explanation of the change.
